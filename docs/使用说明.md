# 学习看电视 · 详细使用说明

配套 `kidtv-guard`，装机与规则设置的完整说明。**机型差异很大**，文中带 `<电视IP>`、`<桌面包名>` 的地方都要换成你自己的。

## 一、默认规则

| 项目 | 默认值 | 可改位置 |
|---|---|---|
| 每日基础时长 | 30 分钟 | 电视「家长设置」/ 手机面板 |
| 允许时段 | 08:00–21:30 | 同上 |
| 一轮题量 | 5 题 | 同上 |
| 及格线 | 80%（答对 4 题） | 同上 |
| 通过奖励 | +10 分钟 | 同上 |
| 当前教材 | 三年级上册（100 题） | 手机面板「教材」卡片 |
| 家长密码 | 首次启动时设置（示例 123456） | 面板「修改家长密码」 |

判定规则：前台不是白名单应用就开始计时；时间用满或当前不在允许时段 → 弹拦截页。

## 二、孩子端

1. 打开任意视频 App 正常看，后台每 5 秒累计一次。
2. 时间用完 → 全屏「时间到啦」页，只有两个按钮：
   - **去做题换时长**
   - **我是家长（输密码放行）**
3. 答题：选完立刻判对错并显示解析，点「继续」，答完后「看结果」。
4. 结果两个出口：
   - 通过 → 点「完成」回到刚才那个视频 App 继续看（不用重开）；
   - 没通过 → 「再答一轮」当场出新题，或「联系家长解锁」由家长输密码放行 10 分钟。
5. 按键锁：
   - 答题页按返回键只弹提示，按主页键会被 1 秒内拉回，进度不丢；
   - 拦截页同样上锁，按返回只弹提示，按主页桌面闪一下就被拉回。

## 三、家长端

### 电视上
首页显示：今日已看 / 上限 / 剩余 / 允许时段 / 答题轮次 / 当前教材 / 管控是否开启，以及面板地址与二维码。

点「家长设置」输密码后可改：每日时长、允许时段、题量、及格线、奖励分钟、白名单；另有「修改密码」「恢复本册原题」「今日用量清零」「临时放行 30 分钟 / 立即恢复管控」。

### 手机上
手机与电视同一 WiFi，扫码或打开 `http://<电视IP>:8099/`，输密码：

- 查看今日使用情况与当前教材；
- 改全部规则、开关管控、改白名单；
- 切教材（按年级分组，13 册：内置 + 1–6 年级上/下册）；
- 导入题库（粘贴 JSON，导入当前册）；
- 远程放行 10 / 30 分钟、立即恢复管控；
- 修改家长密码。

### 接口速查

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/state` | GET | 状态（含 `bankCount`、`ip`、`panelUrl`、`book`、`bookName`、`books`） |
| `/api/books` | GET | 教材清单 |
| `/api/book` | POST | `{"id":"m3a"}` 切换教材 |
| `/api/config` | POST | `{"daily":30,"wslot":"08:00","we":"21:30","qc":5,"pass":80,"reward":10,"enabled":true,"whitelist":"..."}` |
| `/api/bank` | POST | `{"json":"<题库 JSON>"}` 导入当前册 |
| `/api/resetbank` | POST | 恢复当前册原题 |
| `/api/clear` | POST | 今日用量清零 |
| `/api/unlock` | POST | `{"min":10}` 远程放行（1–180 分钟） |
| `/api/relock` | POST | 取消放行 |
| `/api/pwd` | POST | `{"new":"新密码"}` |
| `/qr.png` | GET | 面板二维码（无鉴权） |

所有 `/api/*` 都需要请求头 `X-Pwd: <家长密码>`。

## 四、装到另一台盒子

```bash
adb connect <盒子IP>:5555
adb install -r kidtv-guard-v1.9.apk
adb shell monkey -p com.kidtv.guard -c android.intent.category.LAUNCHER 1
# 进程被杀后手动拉回服务
adb shell am startservice -n com.kidtv.guard/.GuardService
```

装完要做的三件事：

1. 设家长密码；
2. **改白名单**（把你的桌面包名、设置、SystemUI 加进去，见 README）；
3. 在系统的「自启动管理 / 权限管理」里允许本应用自启动，否则开机后服务不会自己起。

## 五、题库

- 12 册，每册 100 题 = 数学 50（苏教版单元顺序）+ 语文常识 50，共 1200 题。
- 正确答案位置随机分布（A/B/C/D 各约 25%），不是固定 A。
- 导入格式：

```json
{"items":[
  {"q":"9+9=?","a":["17","18","19"],"k":1,"tip":"9加9等于18"}
]}
```

- 重新生成：`python3 tools/assemble.py`（会重写 `app/src/main/assets/bank/*.json` 并打印每题答案分布）。

## 六、已知限制

1. 不防卸载 / 强制停止（老盒子做不了 Device Owner）。
2. 进程被杀只有开机时拉回；覆盖安装 APK 后要手动打开一次 App。
3. 前台判定用 `getRunningTasks`，Android 7 以上会失效（新设备请用 StudyOnTV 等方案）。
4. HOME 键靠服务每 1 秒拉回，屏幕会闪一下。
5. 锁 30 分钟自动失效，防止异常退出把电视永久锁住。
6. 只在 Android 4.4.2 / armv7a 的运营商盒子上做过完整验证，其他机型需自行调整白名单并观察行为。

## 七、验证记录（去标识）

| 项目 | 结果 |
|---|---|
| 编译 | Gradle 7.6 + AGP 7.4.2，`clean assembleDebug` 通过，~475 KB |
| 装机 | Android 4.4.2 盒子 `adb install -r` 成功 |

| 分册 | 12 册切换均读到 100 题；force-stop 后当前册仍保留 |
| 答案分布 | 各册 A/B/C/D 均约 25%（例：三年级上册 A21 B21 C25 D33） |
| 面板 | 手机面板 HTML/JS 校验通过，全部接口实测连通；未在多种手机浏览器上渲染验证 |
